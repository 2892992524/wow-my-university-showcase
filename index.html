项目概述

本项目是一套完整的校园社区解决方案，包含微信小程序/H5 用户端、Vue 3 管理后台和 Go 语言 REST API 后端。 涵盖社区帖子、校园活动、兼职信息、闲置交易、搭子组队、商家优惠、课程表等核心业务模块， 并具备内容审核、用户管理、权限控制等运营能力。

技术栈

用户端UniApp · 微信小程序 / H5
管理后台Vue 3 · Element Plus · Vite
后端Go · MySQL · RESTful API
测试Playwright E2E（管理后台）
部署Linux · Nginx · Shell 脚本
